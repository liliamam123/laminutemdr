Solveur interactif

Ton cube, solution par solution.

Renseigne les couleurs des six faces, puis suis les mouvements du solveur un par un.

1 · Entre les couleurs

Tiens le cube avec la face du haut vers le haut et la face avant devant toi. Clique d'abord une couleur dans la palette, puis les cases correspondantes. Les lettres indiquent les faces : U haut, D bas, F devant, B derrière, L gauche, R droite. Les centres définissent les couleurs de référence.

Le cube affiché est résolu. Remplace les couleurs pour commencer.

Regarde le mouvement Chaque tour dure environ 2 secondes. Garde le cube orienté comme à l’écran.
